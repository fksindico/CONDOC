# Pacote de documentação — PRD v3.0

Este pacote contém especificação e orientação para desenvolvimento, não o software pronto.

## Fonte de verdade

docs/prd/PRD_Mestre_v3.md contém o PRD integral. docs/api, docs/ui e docs/deployment são extrações literais do mestre e não devem criar regras divergentes. AGENTS.md e core/AGENTS.md orientam agentes. A pasta docs/phases contém prompts de execução por fase. A matriz de aceite começa com todos os itens não executados.

## Uso

Copie esta estrutura para a raiz do repositório de desenvolvimento, preservando diretórios. Antes de sobrescrever documentação existente, compare e confirme. Inicie pelo prompt da fase 0. Em aplicação existente, primeiro produza inventário e gap analysis. Não avance sem dependências e evidências.

Os scripts de instalação, migrations e backup descritos são requisitos a implementar. Nenhum comando de instalação de aplicação está entregue como executável. Supabase Cloud/infra reais exigem credenciais e autorizações do responsável.

## Escopo inegociável

Gestão de criação e modificação documental, sem votação, quórum ou apuração. Concordância consultiva não é aprovação. Identidade restrita e publicação exclusiva do síndico.

## Validação do pacote

Manifesto contém hashes e tamanhos dos documentos. A validação verifica arquivos, estrutura e rastreabilidade documental, não execução de testes do sistema.
