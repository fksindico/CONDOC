# CONDOC DB-1.0

Modelo e migrations de referência para núcleo cadastral/documental Supabase self-hosted. Ler documentação antes de executar. SQL não homologado em Postgres nesta entrega. Base existente exige adaptação incremental. Nenhum segredo, dado real ou software de backend é fornecido. Rotinas administrativas estreitas e módulo participação estão explicitamente pendentes.
